

## Esclarecimento necessário

O nome "Antigravity" não corresponde a nenhum produto Google conhecido para IA conversacional, nem a nenhum conector MCP disponível no Lovable.

### Produtos Google para IA conversacional que existem:

| Produto | Descrição |
|---------|-----------|
| **Dialogflow CX** | Plataforma de chatbot com fluxos visuais (já parcialmente integrado no zapiWebhook) |
| **Vertex AI / Gemini** | Modelos de linguagem (Gemini Pro, Flash, etc.) |
| **Google AI Studio** | Interface para testar modelos Gemini |
| **Agent Builder** | Construtor de agentes conversacionais no Google Cloud |

### Recomendação

Como o objetivo é usar o modelo **mais em conta para conversação**, a melhor opção já disponível sem configuração extra é o **Lovable AI Gateway** com o modelo `google/gemini-2.5-flash-lite` — que é o Gemini mais barato, roda direto via Edge Function, sem precisar de API key externa nem MCP.

### Próximo passo

Se você confirmar o nome correto do produto ou compartilhar um link, posso investigar a integração. Caso contrário, posso implementar a migração para Gemini Flash Lite via Lovable AI Gateway conforme o plano anterior.
